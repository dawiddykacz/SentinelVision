# SentinelVision - Multi-Camera AI Security System

SentinelVision is a distributed video surveillance system utilizing Artificial Intelligence (YOLOv8) for real-time threat analysis. The system processes video streams from multiple cameras (mobile devices), detects dangerous events, and provides a live preview via a web dashboard.

## 🚀 Key Features

* **Fall Detection (YOLOv8-Pose):** Advanced skeleton analysis (comparing head vs. pelvis Y-coordinates), making it resilient to various camera perspectives and falls along the Z-axis.
* **Dangerous Tool Detection:** Automatic detection of knives, baseball bats, and scissors.
* **Crowd & Panic Analysis:** Detects multiple people running simultaneously, indicating potential panic or crowd emergencies.
* **Multi-Camera Dashboard:** A web-based control panel served by Spring Boot, dynamically displaying streams from all active cameras with a short delay (~5 seconds, Near Real-Time).
* **Evidence Recording:** Automatically annotates threat frames (drawing red bounding boxes) and saves them as isolated video clips (`_alert.mp4`).

## 🏗 System Architecture

The project consists of three main modules communicating asynchronously via Apache Kafka:

1. **Mobile Application (React Native / Expo):**
   Acts as a wireless IP camera. It records and sends video in 5-second chunks (Multipart) to the server, tagging them with a unique session identifier (UUID).

2. **Backend (Java / Spring Boot):**
   Manages camera sessions, receives video chunks, saves them to a shared disk, and notifies the AI module via Kafka. It also utilizes an in-memory **H2 Database** for fast data handling and serves the HTML/JS dashboard to the end user.

3. **AI Module (Python / YOLOv8):**
   Acts as a Kafka consumer. It fetches information about newly uploaded files, analyzes the frames for threats, and saves the processed evidence back to the shared disk.

### Technologies Used:

* **Frontend:** React Native, Expo, CSS Grid (Web Dashboard)
* **Backend:** Java 17, Spring Boot, H2 Database
* **AI / ML:** Python 3.10, OpenCV (Headless), Ultralytics YOLOv8 (Object & Pose)
* **Infrastructure:** Docker, Docker Compose, Apache Kafka, Zookeeper

## ⚙️ Prerequisites

* **Docker & Docker Compose** (running Docker Engine)
* **Node.js** (to run the mobile app development server)
* A smartphone with the **Expo Go** app installed (or an Android/iOS emulator)

## 🛠 Installation & Setup

### 1. Run the Infrastructure (Backend, Kafka, AI)

The backend and analytics modules are fully containerized. 
Open a terminal in the root directory of the project (where the `docker-compose.yml` file is located) and run:

```bash
docker-compose up -d --build
```

*Docker will pull the necessary images, build the Java application, download the AI models (yolov8s.pt, yolov8s-pose.pt), and connect everything within a single internal network.*

### 2. Configure the Mobile Application

The mobile app needs to know where to send the video chunks.

1. Find your computer's local IP address on your Wi-Fi network (e.g., `192.168.1.X`).
2. Open `App.tsx` and update the `BASE_URL` variable:

   ```typescript
   const BASE_URL = 'http://192.168.1.X:8088/api/camera';
   ```

### 3. Start the Cameras (Mobile App)

In the mobile application directory, start the Expo server:

```bash
npx expo start
```

Scan the QR code with the Expo Go app to turn your phone into a surveillance node, then press the "Start Broadcasting" button.

## 🖥 Using the System

* **Live Dashboard:** Open your web browser and go to `http://localhost:8088`. You will see a dynamic grid showing feeds from all currently broadcasting cameras.
* **Reviewing Alerts:** All recordings, including those generated by the AI (ending with `_alert.mp4`), can be found in the newly created `uploads/` folder in your project directory (thanks to Docker volume binding).
